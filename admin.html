Hướng dẫn Admin

Cách vận hành hệ thống
Tạo tài khoản người chơi

1. Firebase Console → Authentication → Users → Add user

2. Nhập email + mật khẩu → user đăng nhập game

3. Profile tự tạo với role: player

Cấp quyền Admin

Realtime Database → users / {uid} / profile / role = "admin"

Hoặc dùng nút → Admin trong tab Người chơi (khi đã là admin).

Firebase Rules

Xem file README.md trong project để copy rules đầy đủ.

Lỗi Permission denied = rules chưa publish hoặc chưa set role admin.
